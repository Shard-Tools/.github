# 🔧 Shard Tools

[Shard Tools](https://shard.tools/) provides 290+ free browser-local utilities for PDFs, images, developer data, text, calculations, documents, and everyday tasks, with optional MCP support for AI assistants.

## 🔒 Browser-local by design

- Supported browser file tools process files locally on your device
- Files selected in those tools are not uploaded for processing
- No Shard Tools account required
- Free browser tools
- Built for desktop and mobile browsers

## 🤖 AI assistant and MCP support

AI assistants can discover tools, perform deterministic calculations, and use selected Edge Assisted file actions through the [Shard Tools MCP endpoint](https://shard.tools/mcp).

**Processing boundaries matter:** browser file tools run locally. Edge Assisted MCP file actions send file bytes to Cloudflare for that request. Capabilities, supported formats, and limits vary by action.

Read the [MCP setup guide](https://shard.tools/guides/install-shard-tools-mcp) before connecting an assistant.
