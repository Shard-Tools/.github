# Shard Tools

[Shard Tools](https://shard.tools) provides 280+ free browser-based utilities for PDFs, images, developer data, text, calculations, documents, and everyday tasks.

## Browser-local by design

- Files are processed locally in your browser
- No file-upload server for supported tools
- No account required
- Free to use
- Built for desktop and mobile browsers
